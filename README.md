# বাংলা ড্রেস কাটিং — Android source project

Kotlin + Jetpack Compose দিয়ে তৈরি বাংলা ভাষার Android প্রোটোটাইপ।

## বর্তমান সংস্করণ ১.১
- বাংলা হোম স্ক্রিন ও পোশাক নির্বাচন
- ইঞ্চি/সেন্টিমিটার একক নির্বাচন
- বুক, কোমর, হিপ, কাঁধ, জামা, হাতা ও গলার মাপ ইনপুট
- শেষ সংরক্ষিত মাপ ও পোশাকের ধরন ফোনে SharedPreferences-এ রাখা
- পরেরবার অ্যাপ খুললে সংরক্ষিত মাপ আবার দেখানো
- অন্তত একটি ধনাত্মক মাপ না দিলে প্যাটার্ন স্ক্রিনে যেতে সতর্কতা
- প্রাথমিক হিসাব ও ধারণামূলক প্যাটার্ন প্রিভিউ

## Android Studio-তে চালানোর নিয়ম
1. কম্পিউটারে Android Studio (Hedgehog বা নতুন) ইনস্টল করুন।
2. ZIP ফাইল Extract করুন।
3. Android Studio খুলে **Open** নির্বাচন করুন এবং `BanglaDressCutting` ফোল্ডারটি খুলুন।
4. Gradle Sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন। প্রথমবার ইন্টারনেট লাগতে পারে।
5. Android ফোনে Developer options ও USB debugging চালু করে USB দিয়ে যুক্ত করুন; অথবা Android Emulator চালু করুন।
6. উপরের Run ▶ চাপুন।

## APK তৈরি
Android Studio → **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**।
সাধারণত APK পাওয়া যাবে `app/build/outputs/apk/debug/app-debug.apk`-এ। এটি debug APK; Play Store-এ প্রকাশের জন্য signed release build প্রয়োজন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এটি এখনো পূর্ণ পেশাদার প্যাটার্ন-জেনারেটর নয়। প্যাটার্ন চিত্র ধারণামূলক; ১:১ স্কেল-নির্ভুল নয়। বুক/কোমরের এক-চতুর্থাংশ দেখানো প্রাথমিক গাণিতিক ভাগ, সম্পূর্ণ কাটিং সূত্র নয়। পোশাকভেদে ease, dart, armhole, neck depth, seam allowance, কাপড়ের ধরন এবং স্থানীয় কাটিং-পদ্ধতি আলাদা। যাচাইকৃত দর্জি/প্যাটার্ন মাস্টারের সূত্র ছাড়া কাপড় কাটবেন না।

## পূর্ণ সংস্করণে যাওয়ার জন্য পরবর্তী কাজ
1. প্রতিটি পোশাকের জন্য পৃথক প্রয়োজনীয় মাপের তালিকা ও validation।
2. অভিজ্ঞ প্যাটার্ন মাস্টার দ্বারা যাচাইকৃত কাটিং সূত্র ও ease/seam allowance সেটিং।
3. মাপের অনুপাতে ভেক্টর প্যাটার্ন এবং ১:১ স্কেল ক্যালিব্রেশন।
4. PDF export, A4/Letter/বড় পেপার টাইলিং এবং প্রিন্ট ক্যালিব্রেশন।
5. একাধিক গ্রাহকের মাপের প্রোফাইল, নাম/তারিখসহ সংরক্ষণ, edit/delete।
6. হাতা, গলা, কলার, কাফ ও ডিজাইন লাইব্রেরি।
7. বাংলা অফলাইন নির্দেশিকা, পরীক্ষা এবং accessibility।

## কাটিং সূত্র যুক্ত করতে যে তথ্য দরকার
প্রতিটি পোশাকের জন্য নির্ভরযোগ্য কাটিং চার্ট/নিয়ম, প্রয়োজনীয় মাপ, ঢিলের পরিমাণ, সেলাই ভাতা এবং একটি পরীক্ষিত নমুনা প্যাটার্ন দরকার। এগুলো স্থানীয় দর্জি বা প্যাটার্ন মাস্টারের কাছ থেকে যাচাই করতে হবে।
